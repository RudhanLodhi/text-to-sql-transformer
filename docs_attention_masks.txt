Attention Mask Shape Guide
==========================

These functions are defined in:
scripts/train.py

The attention implementation receives attention scores with shape:

    (B, H, Q, K)

where:
    B = batch size
    H = number of attention heads
    Q = query sequence length
    K = key sequence length

The mask must be boolean and broadcastable to this shape. True means
"keep this attention position"; False means "mask this position".


1. create_padding_mask
----------------------

Input:

    x: (B, S)

Here B is the batch size and S is the source sequence length.

Step 1:

    x != pad_id
    (B, S)

This produces True for non-padding tokens and False for padding tokens.

Step 2:

    unsqueeze(1)
    (B, S) -> (B, 1, S)

Step 3:

    unsqueeze(2)
    (B, 1, S) -> (B, 1, 1, S)

Final result:

    src_mask: (B, 1, 1, S)

For encoder self-attention, this broadcasts to:

    attention scores: (B, H, S, S)
    mask:            (B, 1, 1, S)

The final dimension masks padded key positions for every head and every
query position.


2. create_target_mask
---------------------

Input:

    tgt: (B, T)

Here B is the batch size and T is the decoder input length. During teacher
forcing, T is normally one less than the original target length because the
decoder input is tgt[:, :-1].

Padding mask:

    tgt != pad_id
    (B, T)

After two unsqueeze operations:

    pad_mask: (B, 1, 1, T)

Causal mask:

    torch.tril(torch.ones((T, T)))
    (T, T)

After two unsqueeze operations:

    causal_mask: (1, 1, T, T)

Combining the masks uses broadcasting:

    pad_mask:    (B, 1, 1, T)
    causal_mask: (1, 1, T, T)
    result:      (B, 1, T, T)

For decoder self-attention, this broadcasts to:

    attention scores: (B, H, T, T)
    mask:            (B, 1, T, T)

The causal mask prevents position i from attending to future positions
j > i. The padding mask prevents attention to padded key positions.


Example
-------

For B=2, H=4, S=5, and T=6:

    source IDs:       (2, 5)
    source mask:      (2, 1, 1, 5)
    source scores:    (2, 4, 5, 5)

    target IDs:       (2, 6)
    target mask:      (2, 1, 6, 6)
    target scores:    (2, 4, 6, 6)

The masks stay small because dimensions 1 and 2 are broadcast rather than
copied independently for every attention head.
